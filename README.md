# 卢雪莹 · Personal Space

一个把个人经历做成可探索场景、也保留完整文字阅读路径的交互式网站。内容围绕金融工程、AI 实践、研究与视觉创作展开。

[在线体验](https://bread-lxy.github.io/) · [直接阅读正文](https://bread-lxy.github.io/#experience) · [查看项目章节](https://bread-lxy.github.io/#projects)

## 如何体验

| 操作 | 会发生什么 |
| --- | --- |
| 点击开场的 **ENTER** | 字标转场后，角色从像素化海报过渡到实时动画；等待加载时也可按 Enter 继续。 |
| 在首页点击栏目、滚动滚轮或按 ↑↓ | 预览经历、研究、项目、创作、生活五个场景；触屏可左右滑动。 |
| 再点当前栏目或按 Enter | 进入对应正文。首页的“向下浏览”和“跳过首屏”可直接开始阅读。 |
| 点击角色头部或兔耳 | 触发表情与动作反馈；鼠标移动时角色视线随之变化。 |
| 使用正文目录、相关链接或浏览器前进／后退 | 跳到同一篇正文的章节或作品，并恢复相应的阅读位置。 |
| 打开“页面引导”“设置”或 BGM | 查看对话式导览，分别控制音效、音乐、减少动效与高对比度。 |

## 交互设计

### 可回应的 2.5D 角色

首页角色由分层 PSD 素材、网格绑定和浏览器端 Canvas / WebGL 播放器驱动。角色会眨眼、追随视线，并根据当前主题改变姿态与表情；点击头部和兔耳会产生不同反馈。开场海报与实时角色之间有连续的视觉交接。

角色离开视口、页面切到后台或动效被关闭时会停止实时渲染。若 WebGL 或 PSD 加载失败，会退回静态海报；海报也不可用时显示文字提示。正文仍可阅读。

### 从场景进入连续正文

五个封面提供探索入口，首页下方是一份连续的正文。栏目按钮、预览卡片、正文目录和相关项目链接都指向这份正文的具体位置。URL hash 可以直达章节或条目，例如 [`#projects/item/personal-archive`](https://bread-lxy.github.io/#projects/item/personal-archive)；前进、后退时会处理滚动位置与焦点。

首页切换区分“预览”和“进入”，并为触控、键盘与轨迹板惯性分别处理输入。跨场景转场采用各主题对应的纸张、窗口和画面运动；进入正文时，首页字标会交接到页眉；之后仍可使用浮动角色目录返回首页或切换章节。页面引导与主题对白采用逐字显现、可操作的选项和焦点管理。

### 可操作的媒体与声音

创作章节的电视墙主屏提供静音循环预览，其他电视显示封面或信号画面；点击视频后可在媒体视图中观看。插画和生活章节的图片可放大。项目章节内置三个 GLSL 转场演示，可切换效果、播放一次，或拖动进度条逐帧查看。图形能力不可用时会显示静态预览。

BGM 与界面音效独立开关。播放器支持选曲、播放／暂停、进度和音量调整；对白有独立的打字音。音乐默认不会自动播放，视频播放时 BGM 会暂停。首页五个主题按钮的节奏条根据曲目分析数据与当前播放位置响应。

## 技术实现

| 层次 | 实现 |
| --- | --- |
| 页面与构建 | React 19、TypeScript、vinext、Vite；构建时静态预渲染，产物输出到 `dist/client/`。 |
| 内容与路由 | `content/` 中的类型化内容模型；`world-machine.ts` 管理场景状态、确认进入与 hash 路由。 |
| 动效 | GSAP 与 ScrollTrigger 编排开场、场景切换和滚动显现；PowerGlitch 用于局部字标效果。 |
| 图形 | 分层 PSD 网格角色、Canvas / WebGL；OGL 渲染水族景深，原始 GLSL 文件驱动转场演示。 |
| 音频 | Howler 管理 BGM、交互音效与对白声音，播放状态与音量分别控制。 |
| 发布 | GitHub Actions 运行构建、类型检查与测试，再把静态产物部署到 GitHub Pages；无需运行中的后端服务。 |

为兼顾阅读与动效，正文在构建时写入 HTML；角色渲染限制帧率与像素密度，离屏或隐藏时暂停。页面提供键盘可达的按钮与目录、跳过首屏入口、焦点样式、减少动效和高对比度选项。

## 项目结构

```text
app/
  PersonalArchive.tsx       首页、场景切换与全站交互
  world-machine.ts          场景状态与 URL 路由
  AlbumScene.tsx            五个主题的封面组合
  Publication.tsx           连续正文与媒体入口
  ShaderExhibit.tsx         GLSL 转场演示
  character/               角色动作、表情、绑定与回退逻辑
content/                   个人资料、正文、主题、音乐与角色配置
public/                    角色 PSD、图像、音频、字体和 shader
tests/                    内容、交互状态与静态 HTML 检查
.github/workflows/deploy.yml  GitHub Pages 发布流程
```

编辑文字内容主要从 [`content/site.ts`](content/site.ts) 和 [`content/publication.ts`](content/publication.ts) 开始；主题画面配置在 [`content/home-scenes.ts`](content/home-scenes.ts)，对应素材放在 `public/`。

## 本地运行

需要 Node.js 22.13.0 或更高版本。

```bash
npm ci
npm run dev
```

```bash
npm run build
npm run typecheck
npm test
```

`npm run build` 生成可直接部署的 `dist/client/`。推送到 `main` 后，[GitHub Actions](.github/workflows/deploy.yml) 会重新构建并发布。当前仓库使用 `bread-lxy.github.io` 作为 GitHub Pages 个人站点，资源路径从域名根目录加载。
